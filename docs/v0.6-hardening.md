# v0.6.0 Hardening Notes

This release prepares Audit Pro for more reliable client-facing reports.

## 1. Scoring is now crawl-size aware

The previous formula was linear:

```text
100 - critical*8 - warning*3 - info*1
```

That made large sites look much worse than small sites when the same template-level issue repeated across many pages. v0.6 uses `computeSiteScore()` in `lib/hardening.mjs`:

- severity still matters;
- issue area still matters;
- unique issue-code diversity still matters;
- repeated issues are normalized by crawl size;
- low-confidence/manual-verification issues have lower score impact.

The report stores the scoring note at `report.summary.scoring` so downstream agents can explain score changes.

## 2. External links are no longer all treated as broken

Many servers block audit bots, reject `HEAD`, rate-limit, or timeout. v0.6 separates external-link results into:

- `confirmedBroken`: clear 4xx/5xx failures, excluding access/rate-limit cases;
- `blocked`: 403/429 responses;
- `timeoutOrNetwork`: aborts, fetch failures, DNS/network timeouts;
- `unknown`: ambiguous results;
- `ok`: successful checks.

Only `confirmedBroken` generates `BROKEN_EXTERNAL_LINK`. Blocked/timeout/unknown results generate `EXTERNAL_LINK_UNVERIFIED` with `confidence: low` and `manualVerify: true`.

## 3. Heuristics must be reviewable

Checks such as soft 404, intrusive interstitial, JS-heavy thin HTML, and crawlable-link warnings are useful audit signals, but they are not legal/proof-grade facts. New issue fields are supported:

```json
{
  "confidence": "low|medium|high",
  "manualVerify": true
}
```

Future report rendering should expose these fields in the issue table and CSV exports.

## 4. Google AI wording guardrail

Google's public guidance says there is no special magic markup required for AI Overviews/AI Mode beyond being eligible for Google Search and following Search essentials / SEO best practices. v0.6 code comments and docs should avoid overstating claims such as “this field is required for AI Overview citation” unless the source is explicit.

## 5. Still out of scope

- Headless browser rendering for SPA/React sites.
- Backlink data.
- SERP / AI Overview live presence checks.
- Automatic PDF rendering.

These should be handled in future phases.
